4. INTEGRATION ARCHITECTURE
================================================================================

Module Structure:
  /address_discovery_system/sources/county_assessor_phase2.py
    ├─ CountyAssessorPhase2 class (base dispatcher)
    ├─ State-specific methods: _search_texas_county(), _search_florida_county()
    ├─ County-specific methods for high-value counties
    └─ Error handling & fallback logic

Flow:
  1. Input: (county, state, property_name, city)
  2. Dispatch by state
  3. Try county-specific API endpoint
  4. If API fails: Try web scrape fallback
  5. If both fail: Return None
  6. Output: {address, confidence, source} or None

Rate Limiting:
  • Global: 2-5 requests/second across all counties
  • Per-county: Queue requests, implement exponential backoff
  • Retry on 429/503: Wait 5-10 seconds, then retry (max 3 attempts)
  • Cache negative results: Don't re-query same property for 24 hours

Error Handling:
  ✓ Connection timeout (>10 sec): Skip property, log error, continue
  ✓ HTTP 4xx (not found): Log, return None
  ✓ HTTP 5xx (server error): Retry with backoff
  ✓ Malformed response: Log error, continue
  ✓ Invalid address format: Log warning, score 0.70-0.80
  ✗ Must NOT crash on any error

5. COUNTY-SPECIFIC APIs (IMPLEMENTATION OPTIONS)
================================================================================

TEXAS COUNTIES (Primary Target)
────────────────────────────────

Option 1 - Use County CAD REST APIs (RECOMMENDED)
  • County Appraisal Districts maintain web forms
  • Some expose ArcGIS REST endpoints
  • Fallback: Web scrape property details

Option 2 - Use ArcGIS REST APIs (for counties that support it)
  • Endpoint: https://services.arcgisonline.com/arcgis/rest/services/<County>/MapServer
  • Query format: { where: "PROPERTY_NAME LIKE '%name%'", outFields: "*, GEOMETRY", f: "json" }
  • Advantage: Structured JSON responses
  • Disadvantage: Not all counties expose this

Option 3 - Web Scraping (Last Resort)
  • Use BeautifulSoup to parse property details
  • High maintenance (breaks when county updates website)
  • Reserve for counties without API options

RECOMMENDATION: Try ArcGIS REST → Web scrape HTML → Return None


FLORIDA, GEORGIA, OTHER COUNTIES
─────────────────────────────────

Option 1 - County Property Appraiser Web Scrape
  • Each county maintains web search portal
  • Parse HTML responses for property details
  • Implement retry logic for failures

Option 2 - Third-Party Data (Future Phases)
  • Zillow API (Phase 3, separate implementation)
  • Google Maps (already used in Phase 1)

RECOMMENDATION: Web scrape county Property Appraiser portals
