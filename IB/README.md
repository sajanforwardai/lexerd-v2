## 🎯 What This Is

A comprehensive, interactive banking simulation where you:
- Spend 5 days as Sajan Goswami, a first-year analyst at Goldman Sachs TMT
- Work on the NovaEdge Software deal (fictional $2.4B enterprise AI company)
- Learn financial analysis through real banking work (not homework)
- Get feedback from your team: Daniel Chen (Associate), Michael Rodriguez (VP), David Kaplan (MD)
- Track performance across 6 dimensions
- Use an AI Coach for learning support

---

## 🎓 Core Features

### Workspace
- **Chat Interface** — Continuous conversation with bankers
- **Deal Room** — Client context and transaction overview  
- **Financials** — Real-time performance metrics
- **Performance Dashboard** — 6-metric analyst development tracker
- **AI Coach** — 4-level hint system + concept help
- **Technical Reference** — All 9 FIN301 questions integrated
- **Document Library** — Sample pitchbooks and materials
- **Notes & Calendar** — Personal scratchpad and schedule

### Learning Path
All financial concepts embedded in banking workflow (not isolated exercises):

| Day | Focus |
|-----|-------|
| Monday | Orientation + deal context |
| Tuesday | Valuation (Q5: Rapid Growth, Q6: Bond Pricing) |
| Wednesday | Analysis (Q8: Sunk Cost, Q9: NPC vs EAC) |
| Thursday | Integration & applications |
| Friday | Performance review |
