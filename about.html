Best Practices for Fast Results

🏃 Fastest Method (2-3 min per property):

  1. Open Google Maps (maps.google.com)
  2. Search: "[Property Name] [City], [State]"
  3. Look at the top result or map pins
  4. Copy the full address from Google

⚡ Second Fastest Method (2-4 min per property):

  1. Open Apartments.com
  2. Search: "[Property Name] [City], [State]"
  3. Click on the property listing
  4. Copy address from property details (also shows phone number!)

📍 Pro Tips:

  • Group properties by city: Search all Houston properties together (reduces context switching)
  • Use keyboard shortcuts: Cmd+C to copy, Cmd+V to paste (Windows: Ctrl instead of Cmd)
  • Have two windows open: Search engine on left, CSV file on right
  • Most results appear in the top 3-5 search results - don't dig deep
  • If a property name is common, add the county name to narrow results
💡 Tip: For 10 properties, you can find all addresses in 20-30 minutes with this method. Focus on speed over perfection - approximate addresses are better than no addresses.

What to Record

Required (Must Have):

  • Property Name (e.g., "Uptown Dallas Apartments")
  • City (e.g., "Dallas")
  • State (e.g., "TX")
  • Address (e.g., "123 Main St, Dallas, TX 75001")

Address Format Examples:

  • ✓ "123 Main Street, Dallas, TX 75001"
  • ✓ "456 Oak Ave, Houston, TX 77001"
  • ✓ "789 Elm Rd, Austin, TX 78701"
  • ✗ "123 Main St" (incomplete - missing city/state/zip)
  • ✗ "Dallas, TX" (incomplete - missing street address)

Troubleshooting

Property not found on Google Maps

  • Try adding the county name: "[Property Name] [County] County [State]"
  • Try Apartments.com instead (usually has better multifamily listings)
  • Try searching for the property management company name
  • The property may be older/defunct - skip it for now

Multiple results for same property name

  • Add the city to narrow results: "[Property Name] [City], [State]"
  • Look at the correct city in the CSV to identify the right one
  • Use county name if available: "[Property Name] [County] County"

Address looks incomplete

  • Copy the complete address Google shows at the top of the search result
  • Example: "123 Main St, Dallas, TX 75001" ← This is complete
  • Avoid partial addresses like just "123 Main St" without city/state/zip
⚠️ Important: Always include Street, City, State, and ZIP in addresses. Partial addresses will cause import errors.

After Finding Addresses

1. Update the CSV File

Each state has a [state]_property_lookup.csv file (e.g., al_property_lookup.csv). Open it in Excel/Google Sheets and fill in the "Address (to be filled)" column with the addresses you found.

2. Save the CSV File

Make sure to save it with the same filename. The import script will look for it.

3. Run the Import Script

Open Terminal/Command Prompt and run:

python scripts/update_[state]_addresses_from_csv.py [state]_property_lookup.csv

Example for Alabama:

python scripts/update_al_addresses_from_csv.py al_property_lookup.csv

4. Check the Results

You should see output like:

✓ ISLAND OAKS APARTMENTS (Orange Beach) → 123 Main St, Orange Beach, AL 36561 ✓ University Downs Apartments (Tuscaloosa) → 456 University Ave, Tuscaloosa, AL 35401 ... ✅ All addresses successfully updated!

5. Verify Progress

To see how many addresses have been found so far, run:

python scripts/audit_all_states.py
