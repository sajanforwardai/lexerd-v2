USAGE SUMMARY
================================================================================

Installation:
  pip install -r requirements.txt

Start Qdrant:
  docker run -p 6333:6333 qdrant/qdrant:latest

Initialize Client:
  from vector_client import QdrantVectorStore
  vs = QdrantVectorStore(collection_name="group1-rag")

Ingest Corpus:
  stats = vs.ingest_corpus_files(corpus_dir="/workspace/corpus/finance")

Query:
  results = vs.query("options trading strategies", top_k=5)

Run Tests:
  make test
  make test-coverage
  make test-latency

Run Examples:
  python example_usage.py
